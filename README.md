# SCHOOL CONNECT

高校生向けの部活動・学校行事情報共有掲示板の静的デモサイトです。

## ローカルでの確認方法
1. このフォルダをVisual Studio Codeで開きます。
2. `index.html` をブラウザで開きます。
3. またはVS CodeのLive Server拡張機能を利用します。

## ファイル構成
- `index.html` : ページ構造
- `style.css` : デザイン・レスポンシブ対応
- `script.js` : 投稿表示、検索、カテゴリー絞り込み、いいね、デモ投稿
- `requirements.md` : 課題提出用の要件定義書

## 注意
これは静的デモ版です。投稿やいいねはブラウザ内の一時データで、サーバーには保存されません。実際に複数ユーザーが利用するには、Flask等のサーバー、データベース、投稿管理・安全対策の実装が必要です。

## Azure公開
この課題ではAzure App Serviceへの静的サイト公開を行います。App ServiceのOS・ランタイム・デプロイ方法に合わせた設定が必要です。Azureリソースの作成後、公式ドキュメントを確認してデプロイしてください。
